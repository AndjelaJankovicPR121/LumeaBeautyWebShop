# LUMÉA BEAUTY Web Shop

Web application for online cosmetic product sales.

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- React
- JWT Authentication
- Stripe Payment Integration

## Roles

- Customer
- Employee
- Admin

## Features

- Registration and Login
- Product Catalog
- Search, Filtering and Sorting
- Wishlist
- Shopping Cart
- Stripe Payments
- Order Management
- Payment Transactions
- Role Based Authorization
